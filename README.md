# writeups

Source for https://blog.dream-wa1ker.tech (Jekyll on GitHub Pages).

    bundle install
    bundle exec jekyll serve      # http://127.0.0.1:4000

Add a post: `_posts/YYYY-MM-DD-slug.md` with front matter `title`, `date`, `tags` (lowercase-with-hyphens), `description`.
Tags, archive, search index and RSS are generated automatically.
